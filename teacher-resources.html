Course structure

Five paired-week modules with a separate evidence folio

The student pathway contains fifteen substantial theory sections, thirty multiple-choice checks, ten scaffolded written responses and a twelve-card project folio. Work saves in the current browser; Print / Save PDF and the folio JSON backup are the deliberate handover options.

Open Course Validation

Project authority

Use the approved Bread Board plan

The original project drawing controls the board form, curved end pieces and written dimensions. Do not measure the website image, substitute another bread board or add a handle, engraving, feet, hardware or decorative details that are not authorised by the project sources.

Teacher directions and current school procedures control the practical order, demonstrations, supervision, machine permissions, PPE, settings, tolerances, approved finish and workshop response to uncertainty.

Programme and assessment boundary

Keep local decisions explicit

The wider 2025 Stage 5 Timber outcome-coverage matrix maps the Bread Board project across INT5-USE-01, INT5-PRO-01, INT5-DES-01, INT5-INP-01, INT5-EVL-01 and INT5-SAF-01. Teachers must confirm the approved local programme, assessment task, dates, marks, weighting, adjustments and submission requirements separately.

Google Classroom upload is teacher directed and occurs outside this website. Nothing is submitted automatically.
