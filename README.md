# Bread Board Guided Course

This is the revised Year 9 Industrial Technology - Timber companion course.

## Start

1. Extract the complete ZIP.
2. Open `index.html`.
3. Keep the extracted folders together so the plan, lesson pages and images remain available.

The course contains five paired-week modules, a visible syllabus-outcomes section, the original Bread Board project plan and a twelve-card evidence folio.

## Student evidence

- Each module saves student details, quiz progress and written responses in the current browser.
- The folio saves details, captions and compressed photo previews in the current browser.
- Use **Print / Save PDF** before changing devices or clearing browser data.
- The folio also provides a downloadable JSON backup that can be restored to the same folio.
- Nothing is uploaded automatically. Google Classroom upload is a later teacher-directed step and is outside this website.

The original legacy Bread Board repository was not modified. This revised package is local only and has not been pushed or deployed.
